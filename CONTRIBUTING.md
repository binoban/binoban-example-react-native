# Contributing

Thanks for your interest in the Binoban React Native example app.

This repository is a **reference integration** maintained by Binoban Engineering. It is
intentionally minimal and tracks the public Binoban React Native SDK
(`@binoban/react-native`).

## How to help

- **Found a bug or something unclear?** Open an issue describing what you expected and
  what happened, including your Node, React Native, Xcode / Android Studio, and SDK
  versions.
- **Have a fix or improvement?** Open a pull request against `main`. Keep changes small
  and focused on the example's clarity.

## Ground rules

- Never include real credentials, non-production hosts, or customer-specific data.
  Use the placeholders `YOUR_API_KEY`, `YOUR_SOURCE_IDENTIFIER`, `YOUR_API_HOST`, and
  keep `android/local.properties` and any signing material out of version control.
- Keep the example aligned with the Android and iOS examples' feature set
  (Track / Identify / Flush / Reset / Settings / JSON).

## Security

For security issues, do not open a public issue — see [SECURITY.md](SECURITY.md).
